+Client (Android) — kasirmini

Folder kasirmini merupakan aplikasi client Android yang dibuat menggunakan Android Studio (Kotlin + Gradle).
Aplikasi ini berfungsi sebagai frontend kasir mini yang terhubung ke Rest API.

Cara Menjalankan Client:

1. Buka Android Studio

2. Pilih Open Project

3. Arahkan ke folder kasirmini

4. Tunggu hingga Gradle Sync selesai

5. Jalankan aplikasi menggunakan emulator atau perangkat Android

+ Rest API (PHP) — uas_kasirmini

Folder uas_kasirmini merupakan backend Rest API berbasis PHP, yang digunakan sebagai penghubung antara aplikasi Android dan database.

Cara Menjalankan Rest API:

1. Pindahkan folder uas_kasirmini ke:

-htdocs (XAMPP) atau

-www (Laragon)

2. Jalankan Apache & MySQL

3. Import database kasir mini ke MySQL

Buka browser dan akses:

http://localhost/uas_kasirmini

Rest API siap digunakan dan dapat diakses oleh aplikasi Android
